# Character models

- `readyplayer.me.glb`: Ready Player Me sample avatar, MIT-licensed; used as the default character rig.
- `M_Standing_Idle_001.glb`, `M_Walk_001.glb`, `M_Run_001.glb`: Ready Player Me animation library
  (github.com/readyplayerme/animation-library). Ready Player Me's licence allows these clips on Ready Player Me avatars
  only, so they are never applied to another rig.
